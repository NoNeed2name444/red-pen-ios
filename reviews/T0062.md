### R1. GraphDepthKeeper.swift:490-491 and :494: the on/glowpx state shades nothing extra

old (490-491):
```
            let shaded: [SCNMaterial] = space && !perPixel ? Self.materials(under: nil, more: more)
                                                            : Self.materials(under: world, more: more)
```
new:
```
            let shaded: [SCNMaterial] = space && !perPixel && !glowPixel ? Self.materials(under: nil, more: more)
                                                                          : Self.materials(under: world, more: more)
```
old (494):
```
                if space, glowPixel == false, perPixel == false, mode == .light, !more.contains(material) { continue }
```
new:
```
                if space, !perPixel, mode == .see, !more.contains(material) { continue }
```
Why: for Space without `-graphDepthPerPixel`, `shaded` holds only `more`,
whatever glowPixel is. So :494 never fires, and in on/glowpx no glow gets
the shader, although brief step 3 says Space's glows get the per-pixel light
shader in that state.

After the change:
- on: still only `more`.
- on/glowpx: `more` plus the map's added-light materials. See-through bodies
  stay on gate opacity.
- on/pixel: still everything.

### R2. GraphDepthKeeper.swift:180: the opacity probe reads encoded values, not light

old:
```
        return Float(top) / 255
```
new:
```
        // SceneKit blends in linear light and the snapshot is sRGB: read it as light
        let v: Float = Float(top) / 255
        return v <= 0.04045 ? v / 12.92 : pow((v + 0.055) / 1.055, 2.4)
```
Why: nothing under ios/ sets SCNDisableLinearSpaceRendering, so SceneKit
blends in linear light. White at node opacity 0.5 over black then reads
about 188/255 (0.735) in the snapshot, for both the additive and the solid
plane. Both fail `abs(x - 0.5) <= 0.1` (:132). So opacityFadesLight
(:128) is false on a working device, and Space would read on/glowpx.

With R1 alone, that would put the per-pixel shader on Space's glows
everywhere: the fragment cost that ruling 4 removes. R1 and R2 go
together. If C2 still reads on/glowpx after R2, node opacity really does
fail on that device.

I could not run SceneKit here. This rests on SceneKit's documented default.

### R3. Graph3DView.swift:2336, inside `opened(_:)`: the double tap while flown in

old:
```
                frame(animated: true)
```
new:
```
                recentre()
```
Why: frame() does not clear `flown` or `flownID`. recentre() does
(:1907-1912). A double tap on empty space during a fly-in therefore frames
the whole map, but the region pill stays: flownID reports to
`touch.flown`. The next window turn's refit() (:1957-1963) then flies back
into the folder.

In the whole view, recentre() is exactly frame(animated: true): flown is
already nil, and flownID's didSet returns on no change.

### R5. GraphDepthTests.swift:141: D4e's label says a different rule from its check

old:
```
    check("D4e \(name): the band's end at least 0.75 of the reach past its start, and k 1 (a straight ramp)",
```
new:
```
    check("D4e \(name): the band ends at least 0.75 of the reach past the focus (0.55 past its start), and k 1",
```
Why: the check is `b - a >= 0.55`, which is b >= 0.75 with a = 0.2. It is
not 0.75 past the start, which Space Smooth (0.55) would fail. This changes
the label only, not the check.

## Open (the owner's call, not a repair)

Space gets no real depth. The suites log A = 0.0 for all three Space sample
maps (preview, big vault, scale). The Neurons get 0.575, 0.575 and 0.465.

I ran a scratch copy of GraphTilt with the rule split in two halves. In 11
of the 12 Space plans the cosmic suite builds, both halves fail at A = 0,
at 0.15·H and at 0.35·H. The halves are the crisp-pair overlap and the
fly-in cover. The one plan with a single galaxy passes all of them.

So the rule rejects Space's flat tilted layout itself. It does not measure
what depth costs. Each galaxy's disc is its whole reach (`galaxyReach`, up
to H itself) and is taken as a sphere, while the 45° pitch foreshortens the
sheet by cos 45°.

This is not the brief's stop case, which needs A = 0 in both themes. But
U3 is inert in Space. The choice is the owner's: foreshortened discs, a
smaller cluster radius, or spreading the galaxies.

The cosmic "lift" check is vacuous at A = 0: it passes on 371b5698 once
GraphTilt.swift is present.
